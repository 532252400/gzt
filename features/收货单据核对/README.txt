收货单据核对 - 功能包
========================

功能说明：
  上传 Receiving Record Excel，核对通知收货 vs 到货数据，
  列出差异明细

服务端函数：
  run_rc(fp)  - 在 功能_收货单据核对.py 中

前端调用：
  go('rc')  - 上传Excel后自动调用

Excel格式要求：
  工作表名必须为 "Sheet2"
  第1-2行=表头
  第3行起=数据

  B列=通知收货SKU  C列=通知收货品名  D列=通知收货数量
  F列=到货SKU     G列=到货品名     H列=到货数量

使用方法：
  python 功能_收货单据核对.py <Excel文件路径>

输出：
  控制台显示核对结果（差异明细）
