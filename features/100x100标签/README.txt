100×100 打印标签 - 功能包
============================

功能说明：
  上传手机壳装箱Excel，生成10×10cm打印标签HTML文件
  
服务端函数：
  run_lbl100(fp)  - 在 功能_100x100标签.py 中
  
前端调用：
  go('lbl100')  - 上传Excel后自动调用
  
Excel格式要求：
  方案A（有SKU列）:
    A列=SKU  B列=品名  C列=型号  D列=包数
    E列=单包数量  F列=采购量  G列=箱号
  
  方案B（无SKU列）:
    C列=SKU  D列=品名  E列=型号  F列=包数
    G列=数量  H列=总量  I列=箱号

使用方法：
  python 功能_100x100标签.py <Excel文件路径>

输出：
  生成的HTML标签文件在 output/ 目录下
