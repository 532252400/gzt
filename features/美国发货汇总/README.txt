美国发货汇总 - 功能包
========================

功能说明：
  上传发货单Excel，生成按区域（东北部/东南部/西部/中北部/中南部）
  分组的美国发货汇总Excel表

服务端函数：
  run_us(fp)  - 在 功能_美国发货汇总.py 中

前端调用：
  go('us')  - 上传Excel后自动调用

Excel格式要求：
  Sheet1（发货单信息）:
    A=货件单号  B=物流中心编码  C=物流商
    D=物流渠道  E=物流商单号   G=国家  H=货件单号

  Sheet5（箱数/重量/体积）:
    A=货件单号  B=箱数  C=重量(kg)  D=体积(m3)  E=类型

使用方法：
  python 功能_美国发货汇总.py <Excel文件路径>

输出：
  生成的汇总Excel在 output/ 目录下
