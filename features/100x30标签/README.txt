100×30 提货标签 - 功能包
============================

功能说明：
  上传司机提货信息Excel，生成100×30mm提货标签HTML文件
  
服务端函数：
  run_lbl30(fp)  - 在 功能_100x30标签.py 中
  
前端调用：
  go('lbl30')  - 上传Excel后自动调用
  
Excel格式要求：
  每行一条记录，前12列:
  1=区域/仓库代码  2=客户名  3=箱数  4=重量(kg)
  5=体积(m3)      6=日期    7=时间  8=司机名
  9=车牌号        10=电话   11=备注

使用方法：
  python 功能_100x30标签.py <Excel文件路径>

输出：
  生成的HTML标签文件在 output/ 目录下
